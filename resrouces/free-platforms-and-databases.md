## Free Platforms & Databases for Projects

Free tiers you can use to build and host the ORM/ODM examples in this repo.

### Free Hosting / Deployment Platforms

| Platform | Good For | Link |
|---|---|---|
| Vercel | Frontend + serverless functions (Next.js) | [vercel.com](https://vercel.com) |
| Netlify | Static sites + serverless functions | [netlify.com](https://netlify.com) |
| Render | Full backend apps, cron jobs, background workers | [render.com](https://render.com) |
| Railway | Full-stack apps + databases | [railway.app](https://railway.app) |
| Fly.io | Dockerized apps, global deployment | [fly.io](https://fly.io) |
| Cyclic | Node.js backend hosting | [cyclic.sh](https://cyclic.sh) |
| Glitch | Quick prototyping, Node.js apps | [glitch.com](https://glitch.com) |
| GitHub Pages | Static sites/docs | [pages.github.com](https://pages.github.com) |

### Free Databases (NoSQL / Document)

| Provider | Database | Link |
|---|---|---|
| MongoDB Atlas | MongoDB (free M0 cluster) | [mongodb.com/atlas](https://www.mongodb.com/atlas) |
| Upstash | Redis + Kafka (serverless) | [upstash.com](https://upstash.com) |
