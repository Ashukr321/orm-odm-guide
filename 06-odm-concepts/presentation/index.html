Key takeaways
Schema → model → documents in a collection.

Key takeaways:
• Schemas define shape, types, defaults, validation, indexes, virtuals and hooks. unique is an index, not a validator.
• Documents track changes and save only modified paths; use .lean() for read-only responses.
• Embed what is read together and bounded; give unbounded or shared data its own collection.
• Update queries skip save hooks and validators unless you opt in (runValidators, query middleware).
• populate() is extra queries; aggregate() doesn't cast ObjectIds; follow ESR and check explain().
